## CLARA Currently Does Well
- Backend transport, validation, security, persistence, and turn lifecycle are hardened.
- RAG confidence gating and source attribution exist.
- Core flow architecture is defined for kiosk operation.

## Missing / Not Yet Stable
- Frontend hardening for reconnect, strict routing, and kiosk-safe resilience.
- Navigation completion with validated coordinates for all required destinations.
- Admin-lite panel for session visibility and lightweight content control.
- Multilingual response naturalness and consistency refinement.
