# Admin Lite Scope

## Metadata
- Status: Draft
- Owner: Person 3 Fullstack
- Last Updated: 2026-04-24


## Objective
Provide minimum operations tooling for pilot support without building a full admin suite.

## In Scope
- Session list and drill-down viewer.
- Basic filters (time, language, error presence).
- Error inspection with taxonomy codes and turn context.
- Controlled knowledge update workflow hooks (no broad write access).

## Out of Scope
- Full RBAC matrix and multi-tenant controls.
- Bulk workflow automation and advanced analytics.
