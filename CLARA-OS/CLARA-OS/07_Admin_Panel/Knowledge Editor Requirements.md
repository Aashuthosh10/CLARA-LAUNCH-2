# Knowledge Editor Requirements

## Metadata
- Status: Draft
- Owner: Person 3 Fullstack
- Last Updated: 2026-04-24


## Minimal Editing Capability
- Add/update/deprecate knowledge source entries with owner + timestamp.
- Preview how a change maps to department/content entities.
- Require confirmation and change reason for each publish action.

## Safety Controls
- No direct free-form overwrite of production corpus without review.
- Keep revision history and rollback point for each published change.
- Validate schema and source traceability before publish.

## Handoff
- Research drafts and validates content updates.
- Fullstack/backend applies ingestion pipeline updates.
