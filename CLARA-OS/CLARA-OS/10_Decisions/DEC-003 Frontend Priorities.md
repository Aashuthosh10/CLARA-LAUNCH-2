# DEC-003 Frontend Priorities

## Metadata
- Status: Approved
- Owner: Person 3 Fullstack
- Last Updated: 2026-04-24


## Decision
Prioritize strict state routing, websocket resilience, voice overlay correctness, and kiosk CSS hardening before feature expansion.

## Rationale
These risks directly impact kiosk trust and pilot stability.

## Implications
- New frontend features are gated until hardening checklist is near complete.
- QA plans focus on reconnect, cancellation, and state edge cases.
