# Department Overview UI

## Metadata
- Status: Draft
- Owner: Person 2 Frontend
- Last Updated: 2026-04-24


## Data Source
- JSON-driven department cards with canonical fields:
  - Department name
  - HOD/primary contact
  - Key services/programs
  - Location/floor reference
  - Visit instructions/hours (if available)

## UI Requirements
- Card list optimized for quick scanning in kiosk context.
- Search/filter by department name and common aliases.
- Card click should support follow-up actions (navigation, ask more, escalate).

## Content Ownership
- Research owner validates card content and freshness.
- Fullstack owner ensures schema compatibility and rendering stability.
